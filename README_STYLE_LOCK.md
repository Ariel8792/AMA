# AMA Digital Visual System — Master Style Asset Pack v1

## Locked visual concept
**Concepto 02 — Trama Fluida** is the only approved visual source of truth for this pack.

## Important limitation / reconstruction note
The approved master exists as a raster reference, not as its original vector source. The SVG assets in this pack are therefore a controlled vector reconstruction of the approved visual grammar, not a pixel-for-pixel recovery of the original hidden source geometry. From this point onward, consistency is deterministic because the same SVG assets are reused rather than regenerated.

## Production rule
AI image generation may create **photographic content only**. It must not redraw or reinterpret the brand layout, waves, masks, grid, logo, typography, CTA geometry, or palette.

## Locked assets
- `AMA_WAVE_BOTTOM_DEEP_01.svg` — primary lower wave signature.
- `AMA_WAVE_BOTTOM_LIGHT_01.svg` — translucent supporting layers.
- `AMA_WAVE_TOP_MIST_01.svg` — very light upper atmosphere.
- `AMA_FLOW_RIBBON_LIGHT_01.svg` — optional low-opacity internal flow.
- `AMA_MASK_ORGANIC_VERTICAL_01.svg` — portrait/4:5 photo mask.
- `AMA_MASK_ORGANIC_HORIZONTAL_01.svg` — horizontal/banner photo mask.
- `AMA_MASK_ORGANIC_SQUARE_01.svg` — square/community photo mask.

## Hard constraints
1. Do not redraw waves for each new piece.
2. Do not replace the locked masks with arbitrary blobs or circles.
3. Use Source Sans 3 only until a second family is separately approved.
4. Use official logo SVG files only. `#03319F` is logo-only.
5. No added turquoise, violet, green, or gradients outside the AMA palette.
6. Icons are informational exceptions, never decoration.
7. Lines are functional exceptions, never filler.
8. Do not repeat one universal left-headline/right-image layout. The identity comes from the assets, not from a single composition.
9. Institutional trajectory may invert to AMA Deep/Core backgrounds while retaining the same wave geometry.
10. All new masters must pass a visual comparison against `AMA_MASTER_STYLE_REFERENCE_01.png`.

## File governance
Adobe: source/master SVG assets. Canva: operational templates built by importing these exact assets.
